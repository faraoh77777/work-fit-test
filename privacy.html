AI FIT 개인정보처리방침

시행일: 2026년 10월 11일

AI FIT(이하 "앱")은 쇼핑몰의 사이즈표와 상품 사진을 캡처해 올리면 내 체형에 맞는 사이즈를 추정해 주는 앱입니다. 앱은 이용자의 개인정보를 가능한 한 적게 다루도록 만들어졌으며, 아래와 같이 처리합니다.

1. 처리하는 정보와 저장 위치

정보용도저장 위치서버 전송
성별, 키, 몸무게, 신체 치수, 선호 핏사이즈 추정, 캐릭터 체형 표시이용자의 기기 안(브라우저 저장소)전송하지 않음
내 얼굴 사진(선택)캐릭터 얼굴에 표시이용자의 기기 안전송하지 않음
옷장(사이즈표 치수, 상품 사진, 이름·가격·링크)핏 판정, 화면 표시이용자의 기기 안"AI로 입혀 보기"를 쓸 때 해당 옷의 상품 사진과 옷 종류만 전송
사이즈표 캡처 이미지글자 인식(치수 자동 입력)기기 안에서 처리전송하지 않음
익명 기기 식별자(앱이 무작위로 만든 번호)AI 이용 횟수 제한, 부정 이용 방지서버(Supabase)"AI로 입혀 보기"를 쓸 때 전송

앱은 이름, 연락처, 위치, 연락처 목록, 계정 정보를 수집하지 않으며 회원가입이 없습니다.

2. "AI로 입혀 보기" 사용 시 처리

  • 이용자가 이 기능을 누르면 해당 옷의 상품 사진과 옷 종류, 익명 기기 식별자가 앱의 서버(Supabase 서비스)로 전송됩니다. 이용자의 얼굴 사진과 신체 정보는 전송되지 않습니다.
  • 서버는 이 정보를 이미지 생성 서비스(TopView)에 전달해 기본 캐릭터가 해당 옷을 입은 이미지를 만듭니다. 전달된 상품 사진은 해당 서비스의 정책에 따라 처리될 수 있습니다.
  • 만들어진 이미지는 이용자의 기기에 저장되며, 서버는 이미지를 보관하지 않습니다.
  • 생성된 이미지는 AI가 만든 것이며 실제 상품과 다를 수 있습니다. 앱 화면에 "AI 생성 이미지"로 표시됩니다.
  • 서버에 남는 기록은 익명 기기 식별자별 하루 이용 횟수뿐이며, 30일이 지난 기록은 자동으로 삭제됩니다.

3. 외부 서비스

  • Supabase: 이용 횟수 제한과 이미지 생성 요청 중계(서버)
  • TopView: AI 이미지 생성
  • 글자 인식 엔진(Tesseract.js): 처음 사용할 때 인식 엔진과 한국어 데이터를 공개 배포망(CDN)에서 내려받습니다. 이용자의 이미지는 전송되지 않고 기기 안에서 처리됩니다.
  • 앱 화면 파일은 GitHub Pages에서 제공됩니다. 접속 시 일반적인 접속 기록(IP 주소 등)이 해당 서비스에 남을 수 있습니다.

4. 보관 기간과 삭제

  • 기기 안에 저장된 정보는 이용자가 직접 삭제하기 전까지 보관됩니다. 앱의 설정 > 고급 > "이 프로필 데이터 지우기"를 누르거나, 앱 데이터(저장소)를 삭제하거나, 앱을 삭제하면 모두 지워집니다.
  • 서버의 익명 이용 기록은 30일 후 자동 삭제됩니다. 이 기록은 이용자를 식별할 수 없습니다.

5. 이용자의 권리

이용자는 언제든지 기기 안의 정보를 직접 열람·수정·삭제할 수 있습니다. 서버에 이용자를 식별할 수 있는 정보는 저장되지 않습니다. 개인정보와 관련한 문의나 AI 생성 이미지에 대한 신고는 아래 연락처로 보내 주세요.

6. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

이 방침이 바뀌면 앱과 이 페이지에 시행일과 함께 안내합니다.
